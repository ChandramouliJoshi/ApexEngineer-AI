TECHNOLOGY STACK
================
Backend:
  - FastAPI (Python framework)
  - SQLAlchemy (ORM)
  - FastF1 (F1 data API)
  - Pytest (Testing)

Frontend:
  - React 18+ with TypeScript
  - Vite (Build tool)
  - CSS3 (Styling)
  - ESLint (Linting)

Infrastructure:
  - Docker & Docker Compose
  - Python virtual environment
  - NPM for package management


PROJECT DESCRIPTION
===================
ApexEngineer-AI is a Formula 1 analysis and telemetry dashboard application that:
- Analyzes F1 race data and telemetry
- Provides driver and engineer comparisons
- Offers sector and corner analysis
- Includes AI-driven scoring and recommendations
- Features interactive visualizations
- Caches F1 data locally for performance
